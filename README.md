# CT投影デモ ― Shepp–Loganファントムとサイノグラム

CTの画像再構成の基礎となる**投影処理（Radon変換）**を視覚的に学ぶための、Streamlit製の教育用アプリです。Shepp–Loganファントムに対して平行ビーム投影を行い、投影方向の変化とサイノグラムの生成過程をアニメーションで確認できます。

## 主な機能

- **Shepp–Loganファントムの表示**：256 × 256画素のファントムを表示します。
- **投影数の設定**：サイドバーで投影数を1～360から選択できます。
- **投影方向のアニメーション**：「投影処理開始」を押すと、ファントムの周囲の赤い矢印が投影方向を示しながら回転します。
- **サイノグラムの逐次表示**：矢印の動きに合わせて、各角度の投影データがサイノグラムに順番に追加されます。

投影角度は**0°以上360°未満**の範囲で等間隔に設定されます。サイノグラムの横軸は投影角度（Projection angle）、縦軸は検出器位置（Detector position）です。

## 使い方

1. サイドバーの「投影数」を設定します（例：30、90、180、360）。
2. 「投影処理開始」ボタンを押します。
3. 左側のファントムで赤い矢印の回転を観察します。
4. 右側でサイノグラムが徐々に作られる様子を確認します。

投影数を変えて実行すると、角度方向のサンプリング密度とサイノグラムの違いを比較できます。

## ローカル環境での起動

Pythonが利用できる環境で、`app.py` と `requirements.txt` を同じフォルダに配置してください。

### Conda環境を利用する場合

```bash
conda create -n medicalai python=3.11 pip -y
conda activate medicalai
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

すでに `medicalai` 環境を作成済みの場合、環境の作成は不要です。表示されたローカルURLをブラウザで開いてください。

## 使用ライブラリ

- Streamlit：操作画面
- NumPy：数値計算
- Matplotlib：画像・サイノグラムの描画
- scikit-image：Shepp–LoganファントムおよびRadon変換

## 授業で確認したいポイント

- 1方向の投影データは、被写体をその方向に沿って積分した一次元データであること
- 投影角度を変えると、得られる投影データの形状も変化すること
- 多方向の投影データを並べると、サイノグラムが形成されること

**注：** 本アプリは投影処理を理解するためのデモです。画像再構成（逆投影・フィルタ補正逆投影）は搭載していません。また、理想化した平行ビームモデルを使用しており、実際のX線検出器の計測過程を完全に再現するものではありません。
